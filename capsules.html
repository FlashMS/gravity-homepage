GravityAI Capsules

Capsules are the core reasoning units of GravityAI. Each capsule has a single responsibility, deterministic behavior, and no side effects. Together, they form the BinaryAI reasoning engine.

DirectoryInvariantValidator
Ensures required directories exist and are not empty. Eliminates silent failures caused by missing or empty folders.
Invariant Layer
RequiredFilePresenceValidator
Checks for required files such as instruction.md, task.toml, tests, and solution files. Prevents invalid task structures.
Invariant Layer
InstructionAlignmentCapsule
Validates that instructions, tests, and metadata align. Detects contradictions, missing requirements, and mismatches.
Deterministic Reasoning
TestExecutionCapsule
Executes tests in a deterministic environment. Classifies failures as logic errors, environment issues, or structural mismatches.
Deterministic Reasoning
ConsequenceCapsule
Maps invariant and reasoning failures to structured consequences. Enables automated classification of failure modes.
Reasoning Layer
ProvenanceCapsule
Tracks the reasoning path, capsule outputs, and decision chain. Ensures transparency and reproducibility.
Meta Layer
SnorkelCapsule
Specialized capsule for Snorkel/Harbor/Terminus tasks. Validates structure, metadata, environment, and test harness consistency.
Specialized Capsule
ReflexCapsule
Implements GravityAI reflex behavior: confirm → align → act. Ensures stable execution states and predictable reasoning.
Execution Layer
